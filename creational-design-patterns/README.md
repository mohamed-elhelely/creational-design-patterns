# Creational Design Patterns Assignment

This project demonstrates the five Creational Design Patterns using plain JavaScript and Node.js:

- Singleton
- Factory Method
- Abstract Factory
- Builder
- Prototype

Each pattern has its own JavaScript file with a simple example.

## How to Run

Run each case separately:

```bash
node case1-singleton.js
node case2-factory-method.js
node case3-abstract-factory.js
node case4-builder.js
node case5-prototype.js
